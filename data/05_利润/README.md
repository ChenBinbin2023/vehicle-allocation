# 利润模拟数据

以上文件为本次演示新增的情景参数，均非实际价格、采购合同或承运报价，币种 SAR。价格已设为不含税；佣金按折后净收入计算。VPC 暂存默认假设 3 天，可在画布中修改。

演示销售订单从绑定分车快照中挑选 3 家有车门店、每家 2 笔小额数量的模拟订单，车型来自同品牌情景表。它们不是已订订单源记录，也不代表补库存已经售出。数量不超过该门店分车归属数量。原始 data 的库存、销速、路线、运力和整趟干线报价保持独立。

利润口径为贡献利润，暂不包含固定经营费用分摊及税费；所有未知费用保持未知。

城市干线报价用于模拟运输预算；VPC连接为城市坐标示意，不是分段承运合同。补充费用为统一情景费率，实际运行需确认每段运输及整备的报价范围。
