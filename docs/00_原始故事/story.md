# 沙特汽车销售供应链介绍

## 沙特的车辆销售网络的供应链

目前的汽车销售供应链（注意不是汽车生产供应链，那个更加复杂了）是按如下方式：
运往沙特阿拉伯的丰田汽车，其供应链是一套高度定制化、以“全进口模式”与“强力独家代理”为核心的全球跨国物流体系。 [1, 2]
丰田曾因沙特本地劳动力成本高、缺乏成熟配套的零部件供应链等原因，未在沙特本土设立整车组装厂。因此，所有在沙特销售的丰田车辆均依赖于庞大的全球工厂供应体系与本地总代理的无缝对接。该供应链的核心架构可以分为以下四个核心环节： [1, 2, 3, 4]

### 源头供给：全球多工厂联动

沙特市场的丰田车并非全部来自日本，而是根据车型和性价比定位，由丰田的全球网络共同供给： [1, 2]

1. 日本本土工厂：主要向沙特输送高端SUV和轿车（如兰德酷路泽、普拉多以及高端品牌雷克萨斯）。
2. 泰国及海外工厂：沙特极为畅销的紧凑型轿车（如雅力士）以及常年霸占中东皮卡市场的丰田海拉克斯（Hilux），大量由丰田泰国工厂及亚洲其他低成本制造基地生产并向沙特出口。 [1, 2, 3, 4]

### 核心纽带：与独家代理商 ALJ 的深度整合

运往沙特的丰田供应链之所以被称为行业标杆，离不开其长达70年合作的沙特独家总经销商——阿卜杜勒·拉蒂夫·贾米尔公司（Abdul Latif Jameel，简称 ALJ）。 [1, 2]

1. 物流承接：ALJ 不仅是一个销售商，更是供应链上的物流与改装核心。ALJ 旗下的独立物流板块直接承接了丰田的海运清关和沙特内陆的仓储转运。 [1, 2]
2. TPS本地化应用：ALJ 在吉达（Jeddah）设立了获得了丰田官方认证的车辆配件与加装基地（Official Toyota Approved Development Base），直接引入丰田的TPS（精益生产系统）。全球出厂的基础车型运抵这里后，根据沙特客户的本土喜好（如特定的车身彩条、特定影音娱乐系统、本地极端高温所需的增强空调配件等）进行标准化加装与检测，大幅缩减了出厂到交付的定制化周期。 [1]

### 物流运输：海运滚装与港口分拨

1. 海上运输航线：成品车通过大型汽车滚装船（RO-RO）从日本（如名古屋港）或泰国港口出发，穿越印度洋，驶入红海或波斯湾。 [1, 2]
2. 港口双核心布局：沙特西部的吉达伊斯兰港（Jeddah Islamic Port）和东部的达曼国王阿卜杜勒阿齐兹港（Dammam）是丰田车入境的两个最重要口岸。近年来由于中东红海地缘冲突引起的航运紧张，丰田和 ALJ 在全球海运费与供应链波动中通过灵活调整两条航线的比重来平抑风险。 [1, 2]
3. 内陆物流转运：车辆清关后，会进入 ALJ 在吉达和利雅得等主要城市建立的国家级整车配送中心（VPC），随后通过大型多车位运输卡车分拨到遍布沙特全境的销售网点。 [1, 2]

### 售后备件供应链：应对极端环境的“生命线”

沙特气候常年高温多沙（夏季经常超过40℃），且车速较快，车辆损耗率高，因此售后零部件分销是该供应链的重中之重。 [1, 2]

1. 零部件分销中心（PDC）：ALJ 在吉达等地建有极其庞大的现代化中央配件仓库，常年储备超过 140,000 种丰田原厂零件。
2. 本地化配套制造：为了提高供应链响应速度，丰田还与 ALJ 以及日本电装（DENSO）在沙特建立了合资工厂，在当地直接生产制造诸如丰田 Hilux 皮卡的空调和制冷系统配件，实现了部分核心易损件的“本地生产、即时供应”。 [1, 2, 3]

## 沙特的车辆分销网络的供应链

丰田汽车运抵沙特阿拉伯的港口后，从“**分销（Distribution）**”到“**零售（Retail）**”的内陆供应网络，完全由其独家总经销商——**阿卜杜勒·拉蒂夫·贾米尔公司（Abdul Latif Jameel Motors，简称 ALJ）**主导和精益化管理。 

沙特的国土面积辽阔、地形多沙且城市间距离极远，丰田为此建立了一套由三大区域物流中枢、TPS（精益生产）信息流和多层级零售网络交织而成的“主动拉动式”供应网络。以下是具体的网络架构： 

### 港口到核心中枢：三大区域车辆配送中心（VPC）

新车在吉达伊斯兰港（西岸）和达曼港（东岸）完成清关后，立即由 ALJ 的专用公路板车队运往设立在核心经济走廊的车辆配送中心（Vehicle Processing Centers, VPC）：

* **西部枢纽（吉达 Jeddah）**：全面覆盖麦加、麦地那以及红海沿岸中部与南部地区。
* **中部枢纽（利雅得 Riyadh）**：沙特最大的新车消费市场，辐射中央大区的所有核心内陆城市。
* **东部枢纽（达曼 Dammam）**：负责东部省（波斯湾沿岸）等核心工业区。 

**TPS的实际落地（“Goods and Information Flow”）**：在这些中枢里，ALJ 应用了丰田的商品与信息流（GIF）操作系统。一旦零售端有客户下单，车辆在 VPC 的出库、PDI（交车前检查）、本地定制配件加装（如应对沙特热带沙漠气候的增配冷风系统）都会像工厂流水线一样精益化运转，绝不让新车在仓库中盲目堆积。 

### 零售网络（Retail Tier）：直营与分销双轨制

沙特新车市场极度依赖“现货可用性”与“月度贷款可负担性”。因此，丰田在沙特的零售网点规模庞大，主要通过两种路径触达零售客户： 

* ALJ 直营旗舰中心（Toyota Centers）：

  * 在利雅得（如著名的 Olaya St 旗舰店、Khurais Rd 综合体）和吉达（Madinah Road 体验中心），ALJ 建立了集“新车销售、原厂配件、售后保养、汽车金融、保险”五位一体（5S）的超级中心。
  * 供应链支撑：直营店通过 ALJ 自身的金融公司（ALJ Finance）及沙特本地大银行（如 Al Rajhi、Alinma Bank）提供无缝的零售贷款，车辆则直接由就近的 VPC 实时配送。 
* 授权独立车商（Authorized Dealers / Secondary Showrooms）：

  * 在直营中心未覆盖的二三线城镇，以及利雅得、吉达的大型汽车交易集市（Haraj），ALJ 供货给当地大型的汽车经销商集团或独立展厅。
  * 这些车商通过 ALJ 统一的线上批发分销系统进行动态车辆配额申请，满足沙特偏远地区消费者对于丰田 Hilux 皮卡和越野车型的强劲需求。 

### “生命线”网络：售后备件分销网络（Parts Distribution）

在沙特，丰田的备件供应链（Spare Parts）甚至比整车销售网络更为庞大和密集。由于极端高温对车辆损耗极大，丰田在沙特建立了一套“中央库 → 区域库 → 零售网点”的三级备件网络： 

```
[吉达中央零件总库] ── 超过14万种原厂配件 
       │
       ├───> [利雅得/达曼等区域PDC中心] 
       │            │
       │            └───> [500多个直营/授权零部件零售点 & 独立修理厂]
       │
       └───> [Toyota Saudi Select 数字化在线订购直接配送]
```

* ALJ 的零部件分销网络涵盖了500多个实体网点，每月要处理超过 350 个海运货柜的零部件补充。
* 在利雅得（例如 Al Rabwah、An Nasim 等区域），ALJ 设立了专门的备件零售与订购点。零售客户或独立修理厂如果遇到缺货，系统会在 24-48 小时内从就近的区域中心调拨并配送上门。 

### 数字化与愿景 2030 的网络延伸

为了配合沙特的“2030愿景（Saudi Vision 2030）”以及当下年轻消费群体的数字习惯，丰田的分销网络正经历深度线上化： 

* 线上虚拟展厅：通过官方的 Toyota Saudi Select 手机应用（引入增强现实 AR 技术），零售买家可以在线配置车型、申请金融贷款并指定最近的交付中心提车。 
* “Best-in-Town”服务理念：依靠这套全方位的本地分销网络，ALJ 在丰田全球分销商评选中连续 15 年斩获代表最高客户体验的“全球金奖”（Toyota Gold Award）。 

## 霍尔木兹海峡的战争影响对丰田车的供应链影响

霍尔木兹海峡的持续紧张局势对丰田汽车的全球及中东供应链造成了近年来最严重的系统性破坏。由于该区域是丰田的核心海外市场之一（年出口量约 60 万辆），海峡实质上的通行受阻直接从产能、零部件、运输时效以及终端零售四个维度重创了丰田的精益供应链体系： [1]

### 核心车型全球大幅减产

由于海峡封锁导致中东地区汽车分销陷入停滞，加之运费飙升和原油价格波动抑制了燃油车需求，丰田被迫做出了极为罕见的海外大减产决策： [1, 2]

* 减产规模高达10万辆：丰田已正式通知其全球主要零部件供应商，计划逐步将海外市场的产量削减约 10 万辆，这一调整预计将持续到 2027 年初。 [1]
* 核心主力车型受波及：此次减产直接针对销往中东的绝对主力，包括中东常青树兰德酷路泽（Land Cruiser）系列 SUV、海拉克斯（HiLux）皮卡、RAV4，以及卡罗拉旅行版（Corolla Touring）等。其中，明星车型 RAV4 甚至因海峡封锁引发的供应链中断，导致其全球部分地区的销售额在上半年骤降了约 36%。 [1, 2, 3, 4]

### 日本向中东整车出口“断崖式下跌”

由于汽车滚装船（RO-RO）无法安全穿越霍尔木兹海峡进入波斯湾内部港口（如沙特东部的达曼港、科威特或阿联酋港口）： [1]

* 今年 4 月份的数据显示，日本向中东地区的汽车出口量和出口总值暴跌了 90% 以上。丰田单月向中东的出口削减量就占据了其月度正常出口份额的 60% 至 70%。 [1, 2]
* 原本依靠“即时拉动（JIT）”的海外新车交付网络因船舶在非受控区域长时间等待（有时长达 15 天到一个间月不等），导致分销周期被彻底打乱。 [1]

2. 给出各种物流的方案和建议
3. 从综合利润的角度来看推荐的方案
4. 如果从下游零售商回购车辆并重新组合库存是否可以提高利润
5. 对海峡的封锁不同周期（一个月、三个月、半年）不同的方案
