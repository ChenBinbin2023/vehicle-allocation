# 周度分车：从一段业务诉求到可追溯的候选方案

版本：v0.2 · 2026-09-30。承接本目录 01–03 的业务、Dashboard 与口径设计，以及 `../01_周度分车` 的计算图谱。

## 故事主线

Omar 在 CUI 新建 Session「港口受限下的周度分车」，输入：「创建丰田凯美瑞、卡罗拉的分车任务，周期 2026-10-05 至 2026-10-11」。GUI 创建一条任务，下面包含两个车型；分配对象为直营销售中心、授权经销商展厅，最小产品粒度为车型，不拆颜色和配置。

一个 Session 可创建多个任务。缺车型或完整七天周期时先显示待补全任务，补全后才可分析。下周按 Asia/Riyadh 的周一至周日解释，并回显绝对日期。点击任务可返回其分析、参数和历史版本。

## 第一幕：先判断数据能回答什么

用户调用 `/weekly-allocation-analysis`。CUI 依次展示本地执行摘要：读取任务范围、校验门店/库存/路线关联、汇总供需与库存、识别缺失与压力。这些是可核验的执行记录，不是模型的内部思维。GUI 同时进入数据分析 Dashboard。

Dashboard 上层为品牌/全网背景，下层为任务车型的模拟展开，明确分隔口径。全国背景包含：周供给代理 2,010 台、历史周销速 2,404.84 台、自由库存 5,232 台、在途 1,012 台、双港口能力 3,226 台、低于一周自由库存的 7 家网点。可以切换品牌、查看区域与网点库存、月度历史销量和供给趋势、路线压力及数据体检。

所有指标标注来源和时点：供给代理止于 2026-07；库存为 2026-09-29；直营与授权销速窗口不同；运力模板为 2026-09-28 至 10-04。2026-08/09 缺失供给保留为空。指定未来分车周只改变任务周期，不把历史模板变成未来实绩。

CUI 总结三件事：库存不能直接替代未来供应；远距离线路比全网总量更早形成瓶颈；缺真实要货单、车型库存和完整到店时点，因此本轮只能生成候选模拟方案。任务分析版本 A1 与这条消息绑定。

## 第二幕：先解释冲击，再选择参数

用户：「假设霍尔木兹海峡未来关闭，丰田供应下降，东部港口关闭，全部从吉达进入，应该怎么调整？」

系统将其记为假设，打开策略面板并提出建议，不擅自确定下降幅度、不覆盖已算版本。先补充供应下降比例；本地演示中的 SC-WEST 还包含东部始发节点停用，不能自动推断为现实中东部 VPC 存量不可用。门店库存保持原值。

策略建议按车型组展示：畅销补库车型优先评估目标库存和渠道份额；长尾车型评估周转与自愿搭配；长途目的地评估合并装载和到店周期。建议关联 A1 渠道比例、A5 目标周数、A4 及时在途、A7 资格、A9 搭配、B11 资源检查。需求销速不会因供应下降自动降低；不设置保底。

用户在 GUI 输入丰田供应下降 20%、仅西部模板，或在 CUI 输入：「丰田供应下降20%，仅西部，目标库存改为3周并重算」。系统按用户明确指令更新同一份参数草稿。比例先作用于全品牌整数供给，再分摊到各车型；库存和销速不随之缩减。

目标库存常态参考 4–6 周，默认 5 周。危机时 3 周是用户显式选择的敏感性参数，并非推荐的长期目标。降低目标可能不改变配额；系统展示实际变化，不保证改善。

## 第三幕：用三列对比解释，而不是只看一个“更好”的百分比

一次比较冻结三份计算：常态基线（双港口、无供应降幅、默认策略）、受限基线（当前冲击、默认策略）、调整候选（同一冲击、用户策略）。本轮两个受限方案使用完全一致的数据和路线模板。参数变化重新生成版本，不改写旧结果。

结果包含逐车型供给与候选量、逐交易主体的模型需求覆盖率、逐销售网点的分配明细、普通补库与搭配增量、路线数量/车次/预算、资源待核验原因。真实要货满足率显示“未计算”。比较覆盖率使用本轮常态默认规则产生的固定网点×车型需求；按数量加权，政策额外搭配不计为普通需求服务，零分母显示“—”。同时展示当前策略需求，防止降低目标造成虚假改善。

国内运输预算按同路线、同周窗口、车型兼容合载的演示假设，先合并数量，再向上取整车次，每车次8台。每条路线的整趟费用已经含情景系数，不二次乘价。费用按该组数量分摊到网点与交易主体，分摊后的分币总额守恒。路线超载、任务外共享资源占用、未来周期模板、装载兼容与发运时点均保留待核验。预算不含海运、港杂、税费和仓储。

点击网点配额进入既有蓝/黄/灰计算图谱，查看输入、参数及中间过程；点击 CUI 的历史结果始终打开对应 A/R 版本。结果可导出包含数据、规则、冲击、口径与图谱运行的 JSON。全国候选不自动发布到执行台。

## 本地演示与后续接入

本轮前端使用现有 CSV 和确定性的本地计算；Skill 的查询步骤是本地执行摘要，未连接外部 Agent、ERP 或新闻服务。GUI 是完整可交互故事，既有教学算例与27台物流样本保留独立入口。

生产接入还需：真实车型供给/库存/要货与到店时间、独立港口/VPC状态、运输占用与兼容规则、后台任务幂等键、持久化与权限、完整 B11 资源求解和执行发布接口。现有前端候选不声称已完成这些能力。
