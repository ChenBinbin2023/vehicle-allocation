# 前端实施计划

沿用现有 Next/React 页面、卡片、表格、颜色、Session 存储和计算图谱，不增加 UI 框架。

1. 扩充 CSV 只读转换，补充销速窗口、库龄、区域、月度销量和门店路线映射；保留原字段及原始数据。
2. 新增任务域：车型与周期识别、待补全状态、分析快照、场景草稿、三方案运行、固定需求覆盖与整车次运输预算。通过纯函数测试验证边界。
3. 新增数据分析 Dashboard、策略面板、比较与解释页面；复用现有参数编辑器、逐网点结果和计算图谱。
4. 将 CUI 创建 Session/任务、分析 Skill、建议与明确调参命令连接到相同状态。历史链接绑定快照，存储兼容旧 Session。
5. 验证完整故事、缺失周期/比例、输入守恒、运输取整、历史版本、跨 Session 隔离、原工作流回归；完成类型检查、构建及浏览器视觉检查。

验收：一条多车型任务贯穿整个故事；数据来源与模拟假设可见；只问建议不改参数；明确调参可直接重算；供应冲击不修改库存；无要货单不显示虚构履约率；候选资源未核验时不宣称可执行。

## 实施记录

- CSV 转换已扩充：来源库存、窗口、库龄、月份销量、路线映射均保留原粒度；原始 `data/` 未改动。
- 本地任务与三方案计算已实现，复用既有图谱引擎和 Session 持久化；独立教学及执行样本保留。
- 数据模型测试已验证供给整数守恒、库存不随冲击变化、固定需求分母、整车次预算及分币守恒。
- 最终代码复查发现并修复：否定句误改规则、非丰田品牌误改丰田、CUI绕过GUI供给比例边界、多次点击新建任务被当作重试。均补充回归用例。
- 复查范围说明：生产 B11 求解和真实订单满足率不在本地演示交付内，界面保留待核验；CSV上游真实性不由前端验证，按来源模拟性质标注。视觉与原有工作流由完整浏览器回归验证。

### v1.3 与周度分车工作台合并

- 取消“原工作台／策略工作流”两个入口：`Planning.tsx` 已删除，唯一工作台是 `components/strategy/StrategyWorkbench.tsx`。
- 页签六个：数据分析（含数据准备与车型总览内容）、策略调整、分车结果（含方案对比）、计算图谱、校验与发布、执行样本。规则编辑器、计算图谱、结果表、发布校验、27台样本都只有一份实现。
- 两个范围共用同一套页签：CUI 任务范围（数据分析看板 + 三方案对比）与情景与教学范围（四种数据情景试算、历史版本与模拟发布）。任务页右上角“情景与教学算例”切换，情景页有任务时可“返回任务范围”。
- 发布与物流承接仍只发生在资源已核验的教学/算例运行上；任务范围的全国模拟候选保持“待核验”，不生成可执行发布版本。
