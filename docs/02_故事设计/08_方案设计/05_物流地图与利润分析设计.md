# 物流地图与利润分析

核心方案：物流用“城市路线总览 → 门店计划批次”地图；新增产品 Skill `/profit-analysis`，沿用 CUI 执行过程与 GUI 分析画布，引用指定物流快照计算贡献利润。

## 物流地图和成本

- 路线为主维度：港口 → 目的地城市，共享路线只计一次运力和整趟费用。展示计划量、直送量、经 VPC 量、未落实量、运力及干线运费。
- 城市路线基础信息、报价、共享运力与门店归属随物流快照保存。选择路线后下钻门店和计划到店批次，显示数量、D+ 到店日及 VPC；待排时段保持未知。原数据没有真实班次号，不能称为已执行班次。
- 地图使用本地城市坐标。实线为城市干线路线，虚线为 VPC 到门店的示意连接；门店没有精确坐标，不能解释为实际道路导航。
- 干线按共享路线 `ceil(已路由数量 / 每趟装载量) × 整趟报价` 计费并摊分。补充港口处理、PDI、末端配送、VPC 处理及暂存费用，均允许编辑；空值为未知，0 为明确零费用。路线缺口或费用缺项时完整总费用保持待确认。

## 利润 Skill

- `/profit-analysis` 绑定已完成物流画布，独立保存情景快照；不改变分车、库存或执行结果。
- 原 data 没有实际订单售价、采购成本和车型分配。新增 `data/05_利润` 明确标记的模拟订单/车型价格与补充费率，GUI 可编辑，CUI 显示依据。
- 贡献利润 = 不含税净销售收入 − 采购成本 − 归属物流费 − 佣金 − 其他可归属费用。固定经营费用和税费不在默认口径内。补库存不自动产生销售收入。
- 订单按门店已路由数量的平均物流成本摊分（含直送/VPC 比例）；车型和门店严格汇总同一订单集合，利润率按总利润/总收入计算。
- GUI 有订单、车型、门店三个视图；点击汇总项下钻订单，查看成本桥和亏损原因，编辑价格及费率后生成新画布。可切换单港/双港，看到同一销售情景受物流成本影响的利润变化。
- 未落实运输或缺失财务费用的订单，利润显示待确认；不把未知成本当成零。所有结论注明模拟、币种 SAR 及成本覆盖范围。
