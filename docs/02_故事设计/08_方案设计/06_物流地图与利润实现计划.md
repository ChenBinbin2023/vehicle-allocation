# 物流地图与利润实现计划

目标：在现有产品 Skill 中增加物流路线地图及费用拆解，并接入订单、车型、门店利润 Skill。

架构：纯计算模型 → 不可变 Skill 快照 → CUI 事件和 GUI 画布。本地地图复用地理数据，利润继承绑定物流结果；新增模拟数据与源数据明确区分。

技术：Next.js / React / TypeScript，Node 单元测试、Playwright 浏览器验证。

设计依据：[05_物流地图与利润分析设计.md](05_物流地图与利润分析设计.md)。约束：不改现有智能问数、分车算法和已发布库存；无真实价格/班次时不编造来源；未知费用不归零。

审查重点：共享运力和整趟费用只计一次；订单金额与汇总一致；历史快照绑定、缺项传播、零费用与空值区分；地图清楚表达路线和批次。
