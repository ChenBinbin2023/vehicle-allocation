## 4. 三类验收标准

### 4.1 分车计划（故事一前半）

- [ ] 1,812 = 759 + 394 + 394 + 265，逐车型可对回，不重不漏。
- [ ] 四类集合互斥：同一 VIN 不同时出现在两类中。
- [ ] ② 待配订单**没有**在算待分配池时预扣一次、配车后又扣一次。
- [ ] ③ 合理补库用的是**缺口口径**（目标覆盖 − 可自由销售现货），不是"补满至目标库存"。
- [ ] 79 店与 46 主体的数字**没有相加**。
- [ ] 四类比例与危机态全网基线的差异有显式解释。
- [ ] 36 台欠交被显式列出并转交，**没有**被静默塞进本船分配。

### 4.2 逐单物流方案（故事一后半）

- [ ] 六条走廊各自的成本、时效、装载模板可解释。
- [ ] 影子价格有算式、有数值、被实际用于改变分车排序。
- [ ] "达曼 VPC 只接无主安全库存"三规则（V-1/V-2/V-3）被明确写出。
- [ ] 补库车的落位是**按全链路成本**决定的，不是按"离哪个 VPC 近"。
- [ ] 五张方案卡各自能回答：为什么是这条路、单台多少钱、谁确认、例外怎么办。
- [ ] 成本口径没有混用满载摊销价与单台零售价。
- [ ] 缓发 480 台带**处置方式与到店时间**，且不与"已发运"重复计数。

### 4.3 每日回购与调拨（故事二）

- [ ] 23 笔申请全部有归属（放行/驳回/升级），无"待处理无人负责"。
- [ ] 10 笔非例行决策各有四策略依据、成本、源店安全性、确认人。
- [ ] 每笔回购都能对上**三道约束**：上界 / 全网可回购台数 / 源店水位。
- [ ] 双端水位表按**同车型同配置**出，不用品牌总数替代。
- [ ] 调拨单、回购单、运输段、执行回执分别记状态；**到店完成 ≠ 结算完成**。
- [ ] 与故事一共用的 VIN 锁定与运输任务**不重复计数**。
- [ ] 借用/延期的量写回下一轮分车输入，不静默消失。
- [ ] 占用干线空位的调拨按**走廊影子价格**计价，没有"空车价"抢占稀缺运力。

### 4.4 故事一与故事二的咬合

- [ ] 36 台欠交从故事一产出，在故事二被逐笔处置，结果回写。
- [ ] ④ 缓冲 265 台在故事一标为"可释放"，在故事二作为第 2 层候选来源被实际释放（本故事线释放 34 台 = Q-03 32 + Q-05 2）。
- [ ] 走廊影子价格在故事一产出，在故事二被用于调拨计价。
- [ ] 回购可得量回写 `B4` 危机态供给池。

## 5. 口径纪律与风险声明

### 5.1 不能犯的六种口径错误

| # | 错误 | 后果 |
| --- | --- | --- |
| 1 | 在东西港口各放一份供给 | 全国供给被凭空翻倍 |
| 2 | 把"单港口道路能力下降"和"上游供给下降"混成一个参数 | 影响无法归因 |
| 3 | 79 店数字与 46 主体汇总相加 | 门店与账户口径重复 |
| 4 | 用 221.97 / 439.74 SAR 乘一个小单当专车价 | 专车成本被低估 2–4 倍 |
| 5 | 把"480 台缓发"报成"480 台欠交" | 履约率被系统性低估 |
| 6 | 把回购的车同时计入"新供给"和"调拨量" | 全国实物量被高估 |

### 5.2 本故事线的三处**主动修正**（相对上游文档）

| # | 修正 | 出处 | 理由 |
| --- | --- | --- | --- |
| 1 | "利雅得截流"不是省里程（1,360 vs 1,370 km 几乎相等），而是①不进达曼 VPC ②中东部/北部散单重新组板 ③分流吉达 PDI | [故事线一](./01_故事线一_两周船的分车计划与逐单物流.md) §2.2 | 源文档把利雅得截流当成东部默认解；实际条件需补全 |
| 2 | 东部有主订单**默认走 RC3 干线穿透**，而非利雅得截流 | 同上 | 少一次卸车、一次 PDI、一次重装 |
| 3 | "等下一船"阈值从 7 天放宽到 **9–10 天** | [故事线二](./02_故事线二_每日回购与调拨.md) §2.1 | 单港下"下船一车到底直发"比"门店二次装板"车况更好、成本更低 |

### 5.3 风险与合规声明
