
## VPC / VDC ➔ 门店：每天的“精准空投”

在沙特，VPC/VDC（车辆准备/分拨中心）到直营门店的“最后一公里”配送，被行业内形象地称为“精准空投”。这套体系的业务逻辑不是“有了车就送”，而是由极度精准的订单数据驱动、在深夜进行的极限操作。
我们可以从以下几个维度彻底拆解这一每天都在发生的物流微操：
----------------------------------------------------------

## 1. 核心触发机制：绝对的“订单驱动（Order-Driven）”

在沙特，像 [ALJ 这样掌控丰田和雷克萨斯的巨头](https://www.toyota.com.sa/)，其在利雅得或吉达郊外的大型 VPC 库房里，车辆主要分为两种状态：

* 未绑定车辆（Free Stock）：纯商品车，等待分配。
* 已绑定车辆（Allocated Stock）：这是“精准空投”的绝对主力。当沙特本地客户在门店看中某款车型，全款到账、银行贷款审批通过（沙特大量的 Lease-to-Own 汽车金融贷款）或者政府/企业采购的预付款结清的那一瞬间，ERP 系统会将该车的 VIN 码状态变更为“Ready for Delivery（准备交付）”。

一旦状态变更，系统会自动向 VPC 的售前检测（PDI）车间下达工单。PDI 工人会立刻对这台特定的车进行最后的撕膜、清洗、加注基本油液、检测电子系统，并打印出带有客户信息的随车交车单。

## 2. 时间窗口：深夜至凌晨的“潜行运输”

“精准空投”最显著的特征是昼伏夜出。沙特各大城市（尤其是首都利雅得）对货运卡车有着极其严苛的交通管制：

* 白天的限制：为了缓解拥堵，沙特交通总局（TGA）严禁重型卡车在白天及早晚高峰（如 06:00 - 09:00，16:00 - 22:00 等时段）进入城市核心区。
* 时间的倒推：因此，VPC 的调度中心会精准计算。每天下午 16:00 - 18:00，VPC 的出车区就会排满已经做完 PDI 的新车。晚上 22:00 限行令一解除，轿运车队开始集中装板出发。
* 夜间送达：卡车必须在深夜到凌晨 05:00 之间，把车送到利雅得或吉达市内的各个展厅门店。因为这个时候城市空旷，卡车能以最快速度完成投递。

## 3. 运力矩阵：“主动脉”与“毛细血管”的搭配

从 VPC 到门店，拉车的工具跟跨城干线使用的“巨型双层大板车”完全不同：

* 市内限行与地形限制：市区的丰田门店通常建在繁华的商业街（如利雅得的 Khurais Road 或 King Abdullah Road），大板车根本没有空间在店门口转弯、倒车和卸车。
* 小型轿运车（毛细血管）：ALJ 在市内配送中大量使用3车位、2车位的小型双层轿运车，或者单车位的平板小跑车（Flatbed Recovery Trucks）。这种车灵活、车速快，进出店面极其方便。
* 精准配载：调度系统在晚上装车时，会严格按照“路线最优化”拼车。比如一辆 3 车位的小跑车，上面的 3 台车可能分别属于同一条路上的 A 门店、B 门店和 C 门店。司机一路开过去，就像快递员送货一样，定点“空投”，卸完即走。

## 4. 门店交接：“零公里”的责任交接与静态闭环

当深夜小跑车到达门店后，门店正门紧闭，但后方的库房或交付中心灯火通明：

* 无接触/夜间交接机制：原店的值班库管员或保安会出来核对 VIN 码。司机将车从斜坡履带上小心翼翼地倒下来。
* 严苛的静态点检：由于这些车是几个小时后客户就要开走的准交付新车，交接要求极高。接收人员会拿着强光手电，重点检查车漆是否有运输途中的飞石刮蹭、轮毂是否有蹭伤、内饰保护套是否污损。
* 责任划分红线：一旦门店库管在交接单上签字，这台车的货权责任就正式从“物流子公司”移交到了“直营门店”。如果白天销售员交车给客户时发现有刮蹭，只要夜间签了字，这个损失就要由门店自己承担。
* 早晨的完美呈现：清晨 08:30 门店正式开门时，昨晚“空投”过来的新车已经被销售助理贴上了交付红缎带，停在干净整洁的交付区，等待沙特车主前来提车。
